"TypeError: cannot read properties of undefined (reading 'length')"   

This happens when you try to access .length on a value that is undefined.

Common causes:

variable has no value
- e.g. a variable was declared but never assigned
- ensure the variable has a value before using .length

function didn’t return anything
- e.g. a function runs but returns undefined
- make sure the function returns the expected value

missing part of an object path
- e.g. accessing a nested property where something is undefined
- check each step in the object path exists

data hasn’t loaded yet
- e.g. code runs before async data is available
- wait for the data to load before accessing it
